# GameEd 🌊

An interactive gamified learning platform designed for children aged 2 to 5 years old, built around an underwater ocean theme with Donna the Starfish as the guide mascot.

---

## About the Project

GameEd is a web-based early childhood education platform that makes learning feel like play. Children explore an underwater ocean world and visit different zones, each containing a game that teaches a core skill. The platform is designed keeping the target audience in mind — no reading required, large tap targets, audio guidance, and a positive reward system.

This project was built as part of a Design Thinking and Innovation course at university.

---

## The Four Zones

| Zone | Game | Skill |
|------|------|-------|
| English Cove | Bubble Letters | Letter recognition and phonics |
| Math Lagoon | Count the Fish | Counting and number recognition |
| GK Shipwreck | Weather Watch | Weather, seasons and general knowledge |
| Art Grotto | Color the Reef | Color recognition and creativity |

---

## Mascot

**Donna the Starfish** is the heart of GameEd. She guides children through the platform, celebrates their wins, addresses mistakes gently, and lives in her own Ocean Home that grows as children learn and earn shells.

## Key Features

- Underwater ocean world with 4 learning zones
- One game per zone, each with 3 difficulty levels
- Parent account creation with age verification
- OTP protected parent settings panel
- Screen time limit controls for parents
- Shell reward system — children earn shells as they learn
- Donna's Ocean Home — a personal space that grows with the child
- No advertisements
- No in-app purchases at this stage
- All data stored securely — no third party data sharing
